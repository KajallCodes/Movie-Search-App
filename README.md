Movie Search App

A simple and interactive Movie Search App built using HTML, CSS, and Vanilla JavaScript. The application fetches movie data from the OMDb API and displays search results dynamically as the user types.

Features:
> Real-time movie search with debouncing
> Fetches movie data from the OMDb API
> Displays movie posters and titles
> View detailed movie information
> Back button to return to search results
> Dynamic DOM manipulation
> Asynchronous API handling using Fetch API
> Clean and user-friendly interface
Technologies Used:
HTML5
CSS3
JavaScript (ES6)
Fetch API
OMDb API

What I Learned
Through this project, I practiced:

>API integration using Fetch API
> Working with asynchronous JavaScript
> Debouncing user input for better performance
> DOM manipulation and event handling
> Dynamic creation of HTML elements
> Handling API responses and errors
